# Haloscript website

This repository contains the public website for **Haloscript**, a writing app for Mac, iPad, and iPhone. The site introduces the product, explains its main features, and provides public updates without exposing the private application source code.

## In plain English

Haloscript gives novel writers one place to draft, organize scenes, maintain a Story Bible, and sketch ideas on an open whiteboard. The website explains that experience for writers and prospective users.

**Status:** Haloscript is live on the App Store.

## Privacy and repository boundaries

The application source lives separately and is not published here. This repository should contain only website assets and information intended for public release.
